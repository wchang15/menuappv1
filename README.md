# Menu App V1 - Historical Snapshot

**Status: retained for reference; not the current maintained application.**

This repository preserves an earlier version of the React/Next.js restaurant
tablet-menu editor and player, including local storage, Supabase session handling,
and an iOS Capacitor wrapper. It is not the recommended starting point for setup
or engineering review. Legacy dependencies and server routes are not maintained;
do not deploy this snapshot or provide live service credentials.

## Current Work

- [Tablet menu application](https://github.com/wchang15/menu): current source,
  build CI, and documented Storage setup.
- [Restaurant ordering demo](https://github.com/wchang15/restaurant-ordering-demo):
  the separate TypeScript customer ordering and staff workflow, with regression tests.
- [Portfolio case study](https://www.woochangchang.com/restaurant-platform.html).

This repository remains available to preserve its existing source and history.
Current verification claims apply to the linked maintained repositories only.
